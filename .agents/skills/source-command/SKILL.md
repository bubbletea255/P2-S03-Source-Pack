# source-command

Use this skill when the user asks to run the migrated source command `저장`.

## Command Template

현재까지의 대화를 백그라운드 에이전트로 저장합니다. 아래 절차를 따르세요.

## 실행 절차

### 1단계: 저장 범위 결정 (증분 저장)

시스템 컨텍스트의 **Primary working directory** 값을 프로젝트 루트로 사용한다.
체크포인트 파일 경로: `{프로젝트루트}/docs/대화 원본/_checkpoint.md`

해당 경로의 파일을 Read 도구로 읽는다.

- **파일이 없으면** → 전체 저장 모드: 현재 대화 전체를 저장 대상으로 삼는다.
- **파일이 있으면** → 증분 저장 모드: 파일 내 `last_user_message` 값을 확인한다. 현재 대화에서 그 텍스트(앞 120자 기준)와 일치하는 User 메시지를 찾고, **그 이후에 온 메시지들만** 저장 대상으로 삼는다. 일치하는 메시지를 찾지 못하면 전체 저장 모드로 전환한다.

### 2단계: 저장 내용 준비

저장 대상으로 결정된 메시지 범위를 기준으로 아래 두 가지를 준비한다.

**대화 원본 형식**:
```
# 대화 원본
저장일시: YYYY-MM-DD HH:MM
저장 범위: [전체 저장] 또는 [증분 저장 — {이전 체크포인트 이후}]

---

**User**: [사용자 메시지]

**Assistant**: [어시스턴트 응답]

(이하 반복)
```

**대화 요약 형식**:
```
# 대화 요약
저장일시: YYYY-MM-DD HH:MM
저장 범위: [전체 저장] 또는 [증분 저장 — {이전 체크포인트 이후}]

## 주요 주제
- [이번 대화에서 다룬 핵심 주제 2~5개]

## 결정 사항
- [확정된 방향, 선택, 설계 결정]

## 산출물
- [만들어진 파일, 코드, 문서 등]

## 다음 단계
- [미완료 작업, 다음에 이어서 할 내용]

## 핵심 내용 요약
[200~400자 자연어 요약]
```

### 3단계: 파일명 결정

현재 날짜/시간 기준으로 파일명을 만든다.
- 원본: `YYYYMMDD_HHMM_대화원본.md`
- 요약: `YYYYMMDD_HHMM_대화요약.md`

### 4단계: 백그라운드 에이전트 호출

Agent 도구를 `run_in_background: true`로 호출한다. 에이전트 프롬프트에 아래를 모두 포함한다.

모든 경로는 시스템 컨텍스트의 **Primary working directory**를 프로젝트 루트로 삼아 구성한다.

1. **원본 저장**: Write 도구로 `{프로젝트루트}/docs/대화 원본/{원본파일명}` 에 대화 원본 내용을 저장한다.

2. **요약 저장**: Write 도구로 `{프로젝트루트}/docs/대화 요약/{요약파일명}` 에 대화 요약 내용을 저장한다.

3. **체크포인트 업데이트**: Write 도구로 `{프로젝트루트}/docs/대화 원본/_checkpoint.md` 를 아래 형식으로 저장한다 (기존 파일 덮어쓰기).
   ```
   last_saved_time: YYYY-MM-DD HH:MM
   last_saved_file: {원본파일명}
   last_user_message: {이번 저장 범위에서 마지막 User 메시지 앞 120자}
   ```

에이전트는 위 세 파일을 저장하고 바로 종료한다. 읽기 확인이나 추가 작업은 하지 않는다.

### 5단계: 즉시 응답

에이전트 호출 직후 사용자에게 알린다.

형식:
```
백그라운드에서 저장 중입니다.
- 원본: `{원본파일명}`
- 요약: `{요약파일명}`
계속 대화하세요.
```

이후 대화를 계속한다.

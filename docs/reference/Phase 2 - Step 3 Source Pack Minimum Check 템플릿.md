# Phase 2 - Step 3 Source Pack Minimum Check 템플릿

## 목적: Phase 2 분석 전에 “최소 원자료”를 확보했는지 확인

## 1. 이 템플릿의 역할

**Source Pack Minimum Check**는 기업을 깊게 분석하기 전에, 최소한의 원자료가 확보되어 있는지 확인하는 단계입니다.

이 단계의 목적은 분석이 아닙니다.

> **“Phase 2 통합 템플릿을 실행해도 될 만큼 자료 기반이 있는가?”를 확인하는 입구 게이트**
> 

입니다.

---

# 2. 이 단계에서 얻어야 하는 산출물

| 산출물 | 의미 |
| --- | --- |
| 확보된 원자료 목록 | 어떤 자료를 기준으로 분석할 수 있는지 확인 |
| 부족한 자료 목록 | Phase 2 진행 전후로 보강해야 할 자료 |
| 자료 신뢰도 구분 | SEC / 회사 IR / 컨콜 / 외부자료 / 2차 자료 구분 |
| 기준일 확인 | 자료가 최신인지 확인 |
| Phase 2 진행 가능 여부 | Proceed / Conditional Proceed / Hold |

---

# 3. Source Pack Minimum Check의 핵심 원칙

| 원칙 | 설명 |
| --- | --- |
| 완벽한 자료 수집이 목적이 아님 | Phase 2 시작에 필요한 최소 자료 확보가 목적 |
| 회사 자료만 보면 안 됨 | 경쟁사 / 산업 자료가 최소한으로 필요 |
| 최신성 확인이 중요 | 10-K만 보고 최근 분기 변화를 놓치면 안 됨 |
| 출처 신뢰도 구분 | SEC, 회사 IR, 컨콜, 언론, 블로그성 자료를 구분 |
| 부족 자료를 명확히 표시 | 나중에 어떤 자료를 보강해야 할지 남김 |
| 숫자는 가능하면 원자료 기준 | 재무 숫자는 SEC / 실적자료 / 회사 공식자료 우선 |

# 4. Minimum Source Pack 기준

## 4-1. 필수 자료

Phase 2를 시작하려면 최소한 아래 자료가 필요합니다.

| 자료 | 필요도 | 사용 목적 |
| --- | --- | --- |
| 최신 10-K / Annual Report | 필수 | 사업, 제품, 리스크, 세그먼트, 재무 구조 확인 |
| 최신 10-Q / Quarterly Report | 필수 | 최근 분기 변화, 비용 구조, 현금흐름 확인 |
| 최신 Earnings Release | 필수 | 최근 실적, 가이던스, 주요 KPI 확인 |
| 최신 주가 / 시가총액 / EV | 필수 | 현재 시장가격 감각 확인 |
| 회사 공식 웹사이트 / 제품 페이지 | 필수 | 제품 / 서비스 구조 확인 |

---

## 4-2. 권장 자료

| 자료 | 필요도 | 사용 목적 |
| --- | --- | --- |
| Earnings Call Transcript | 권장 | 경영진 설명, 애널리스트 질문, 톤 변화 확인 |
| Investor Presentation | 권장 | 회사가 강조하는 전략, TAM, 제품 포지션 확인 |
| Proxy Statement | 권장 | 경영진 보상, 지배구조, 내부자 보유 |
| 주요 경쟁사 2~3개 자료 | 권장 | Phase 3 경쟁사 분석 준비 |
| 산업 리포트 / 시장자료 | 권장 | TAM / 성장률 / 밸류체인 확인 |
| 최근 주요 뉴스 | 권장 | 실적 이후 이벤트, 규제, M&A, 소송 확인 |

---

## 4-3. 특수상황에서 추가 필요한 자료

| 기업 유형 | 추가 자료 |
| --- | --- |
| Turnaround | 구조조정 계획, 비용 절감 계획, 부채 만기표, liquidity update |
| Cyclical Recovery | 업황 지표, 가격 지표, 재고, 가동률, 공급 증설 계획 |
| Deep Value | 자산가치, 부채 우선순위, 현금 소진, 자산매각 가능성 |
| Post-reorg / Chapter 11 | plan of reorganization, disclosure statement, emergence 자료, 신규 주식 수, warrants, exit financing |
| Biotech / Diagnostics | 임상자료, reimbursement, FDA / 규제 자료, 검사량 / 수가 |
| SaaS / Software | ARR, NRR, customer count, RPO, billings, SBC, retention |
| Semiconductor / Hardware | capacity, utilization, backlog, inventory, capex, ASP, customer concentration |

# 5. 자료 신뢰도 등급

자료를 모을 때는 신뢰도를 구분해야 합니다.

| 등급 | 자료 유형 | 신뢰도 |
| --- | --- | --- |
| A | SEC filing, 감사 재무제표, 공식 실적 발표 | 가장 높음 |
| A- | 회사 컨퍼런스콜, Investor Presentation | 높지만 회사 관점 반영 |
| B | 공식 산업기관, 규제기관, 거래소, 정부자료 | 높음 |
| B- | 신뢰도 높은 금융매체, 전문 리서치 기관 | 보통~높음 |
| C | 일반 뉴스, 블로그, 커뮤니티, 소셜미디어 | 참고용 |
| D | 출처 불명 자료, 홍보성 자료 | 원칙적으로 사용 금지 |

# 6. Source Pack Minimum Check 결과 판정

## 6-1. Proceed

| 조건 | 설명 |
| --- | --- |
| 최신 10-K / 10-Q 확보 | 사업과 최근 재무 확인 가능 |
| 최신 실적자료 확보 | 최근 변화 확인 가능 |
| 제품 / 사업부 자료 확보 | 무엇을 파는지 확인 가능 |
| 현재 시장가격 확인 가능 | 대략적인 valuation 감각 가능 |
| 주요 부족 자료가 치명적이지 않음 | Phase 2 진행 가능 |

---

## 6-2. Conditional Proceed

| 조건 | 설명 |
| --- | --- |
| 핵심 공시는 있으나 산업자료 부족 | Phase 2 진행하면서 보강 가능 |
| 컨콜이 없거나 아직 확인 전 | 통합 템플릿 진행 가능하나 추후 보강 필요 |
| 경쟁사 자료 부족 | Phase 3 전까지 보강 필요 |
| 시장 규모 자료 부족 | Market / Share 모듈에서 보강 |
| 최신 분기 자료 일부 부족 | 주의 표시 후 진행 가능 |

---

## 6-3. Hold

| 조건 | 설명 |
| --- | --- |
| 최신 공시가 없음 | 사업 / 재무 확인 불가 |
| 최근 실적자료 없음 | 현재 상태 파악 어려움 |
| 사업부 / 제품 구조 불명확 | Phase 2 통합 분석 품질 저하 |
| 숫자 출처가 불명확 | 재무 분석 위험 |
| 특수상황인데 법원 / 구조조정 자료 부족 | 기존 주주 가치 판단 불가 |
| 정보 접근성이 너무 낮음 | Watch 또는 Pass 가능 |

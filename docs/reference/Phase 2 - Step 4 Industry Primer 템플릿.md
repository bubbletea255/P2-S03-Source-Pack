# Phase 2 - Step 4. Industry Primer 템플릿

## 목적: 산업을 이해하기 위한 “기초 지도” 만들기

## 1. 이 템플릿의 역할

**Industry Primer**는 특정 기업을 분석하기 전에, 그 기업이 속한 산업의 기본 구조를 이해하는 단계입니다.

이 단계의 목적은 산업 리포트를 완성하는 것이 아닙니다.

> **“이 산업이 왜 존재하고, 누가 돈을 내며, 무엇이 성장을 만들고, 어떤 구조적 리스크가 있는지 이해하는 것”**
> 

입니다.

# 2. Industry Primer가 필요한 경우

| 상황 | 필요도 |
| --- | --- |
| 처음 보는 산업 | 매우 높음 |
| 기술 용어가 많아 사업 이해가 어려운 산업 | 매우 높음 |
| 의료 / 반도체 / 보안 / 광고 / AI 인프라처럼 밸류체인이 복잡한 산업 | 높음 |
| 이미 잘 아는 산업이지만 새로운 세부 분야를 보는 경우 | 중간 |
| 이미 여러 번 분석한 익숙한 산업 | 낮음 |
| 단순 소비재 / 단일 제품 기업 | 낮음~중간 |

# 3. Industry Primer에서 답해야 하는 핵심 질문

| 영역 | 핵심 질문 |
| --- | --- |

| 고객 | 누가 이 산업의 제품 / 서비스를 구매하는가? |
| 구매 이유 | 고객은 왜 돈을 지불하는가? |
| 산업 구조 | 산업은 어떤 하위 시장과 참여자로 구성되는가? |
| 성장 동인 | 산업 성장은 무엇이 이끄는가? |
| 수익 구조 | 산업 참여자들은 어떻게 돈을 버는가? |
| 비용 구조 | 어떤 비용이 큰가? |
| 규제 / 제도 | 산업 성장을 좌우하는 규제나 제도가 있는가? |

# 7. 이 템플릿에서 특히 중요한 점

## 7-1. 산업 설명과 기업 분석을 구분해야 함

Industry Primer는 산업을 설명하지만, 최종 목적은 기업 분석입니다.

따라서 단순히 산업 공부로 끝나면 안 됩니다.

| 단순 산업 공부 | 투자 분석용 Industry Primer |
| --- | --- |
| 이 산업이 무엇인지 설명 | 이 산업 구조가 기업 매출 / 비용 / 해자에 어떻게 연결되는지 설명 |
| 용어 정리 | 용어가 재무 지표와 어떤 관계인지 설명 |
| 성장률 설명 | 어떤 기업이 그 성장의 수혜를 받는지 구분 |
| 기술 설명 | 기술 변화가 가격, 경쟁, 수익성에 미치는 영향 설명 |

---

## 7-2. 이 단계에서 결론을 너무 빨리 내리면 안 됨

Industry Primer에서 하면 안 되는 결론:

| 금지 결론 | 이유 |
| --- | --- |
| 이 회사는 경제적 해자가 강하다 | Moat 단계에서 판단 |
| 이 회사가 경쟁사보다 낫다 | Competition 단계에서 판단 |
| 이 주식은 싸다 | Valuation 단계에서 판단 |
| 이 회사는 매수할 만하다 | Final Memo 단계에서 판단 |

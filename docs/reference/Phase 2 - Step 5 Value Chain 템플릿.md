# Phase 2 - Step 5 Value Chain 템플릿

## 목적: 산업 내 돈의 흐름, 병목, profit pool 파악

## 1. 이 템플릿의 역할

**Value Chain 분석**은 특정 기업이 산업 안에서 어느 위치에 있고, 그 위치가 좋은 자리인지 판단하기 위한 단계입니다.

이 단계의 핵심 질문은 이것입니다.

> **“이 산업에서 누가 돈을 벌고, 누가 비용을 부담하며, 이 회사는 그 흐름에서 얼마나 중요한 위치에 있는가?”**
> 

---

# 2. Value Chain 분석이 특히 중요한 경우

| 산업 / 기업 유형 | 중요도 | 이유 |
| --- | --- | --- |
| 반도체 / AI 인프라 | 매우 높음 | GPU, HBM, 네트워크, 전력, 장비 등 병목 레이어가 수시로 바뀜 |
| 광고 / 플랫폼 | 매우 높음 | 광고주, DSP, SSP, ad network, measurement, publisher 간 수익 배분이 중요 |
| 정밀의료 / 진단 | 매우 높음 | 검사, 병원, 보험, 데이터, 규제, reimbursement 구조가 복잡 |
| SaaS / Cloud | 높음 | 인프라, 플랫폼, 애플리케이션, 고객 workflow 연결이 중요 |
| 전력 / 에너지 / 배터리 | 높음 | 소재, 장비, 제조, 고객, 규제, 공급망 구조가 중요 |
| 소비재 / 단순 제조업 | 중간 | 원재료, 유통, 브랜드, 채널 구조 중심 |
| 단일 제품 기업 | 낮음~중간 | 사업모델 템플릿만으로 충분한 경우도 있음 |

# 5. Value Chain 단계에서 특히 중요한 관점

## 5-1. 매출이 큰 곳과 이익이 남는 곳은 다를 수 있음

| 구분 | 설명 |
| --- | --- |
| 매출 규모가 큰 레이어 | 고객 돈이 많이 지나가는 구간 |
| profit pool | 실제 이익과 가격결정력이 남는 구간 |
| 투자 매력도 | 보통 profit pool에 가까울수록 높음 |

예를 들어 어떤 산업에서는 유통사가 매출은 크지만 margin이 낮고, 핵심 부품이나 소프트웨어 레이어가 profit pool일 수 있습니다.

---

## 5-2. 병목은 일시적 병목과 구조적 병목을 구분해야 함

| 병목 유형 | 의미 | 투자 분석상 해석 |
| --- | --- | --- |
| 일시적 병목 | 공급 부족, 단기 CAPEX 지연 | 높은 이익이 오래가지 않을 수 있음 |
| 구조적 병목 | 기술 난이도, 데이터, 규제, 인증, 고객 lock-in | 해자 후보가 될 수 있음 |

---

## 5-3. 밸류체인 위치는 Phase 3 Moat와 연결됨

Value Chain 단계에서는 해자를 확정하지 않습니다.

다만 아래처럼 **해자 후보**를 Phase 3으로 넘깁니다.

| Value Chain에서 발견한 것 | Phase 3에서 검증할 것 |
| --- | --- |
| 병목 레이어에 위치 | 이것이 지속 가능한 해자인가 |
| 고객 workflow에 깊게 통합 | switching cost가 실제로 높은가 |
| 핵심 데이터 보유 | 데이터가 제품 성능과 retention으로 연결되는가 |
| 공급자가 적음 | 진입장벽이 실제로 높은가 |
| 생태계 중심 위치 | network effect나 platform lock-in이 있는가 |

| 산업 구조가 복잡함 | Pro 표준 |
| 여러 출처를 종합한 고신뢰 산업지도 | Pro 확장 / Deep Research |
| 단순 초안 | Thinking 라이트 가능하지만 권장하지 않음 |
| Thinking 확장 / 헤비 | 템플릿 작성에는 과함. 실제 고난도 분석에서 제한적으로 사용 |

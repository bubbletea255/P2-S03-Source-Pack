# Phase 2 - Step 7 Market / Share 템플릿

## 목적: TAM 착시를 피하고, 현실적 성장 runway를 판단하기

## 1. 이 템플릿의 역할

**Market / Share 분석**은 “시장이 크다”는 주장만 확인하는 단계가 아닙니다.

이 단계의 핵심은 아래 질문입니다.

> **“이 회사가 실제로 접근 가능한 시장은 얼마나 크고, 그중 현실적으로 얼마를 차지할 수 있는가?”**
> 

즉, 이 템플릿은 다음을 구분하기 위한 도구입니다.

| 구분 | 의미 |
| --- | --- |
| TAM | 이론적 전체 시장 |
| SAM | 회사가 실제로 접근 가능한 시장 |
| SOM | 현실적으로 차지할 수 있는 시장 |
| 현재 점유율 | 지금 회사가 차지한 위치 |
| 미래 점유율 가능성 | 점유율을 높일 근거가 있는지 |
| 성장 runway | 현재 매출이 앞으로 얼마나 커질 수 있는지 |

---

# 2. Market / Share 분석이 중요한 이유

성장주 분석에서 가장 흔한 실수는 **TAM 착시**입니다.

| 약한 분석 | 강한 분석 |
| --- | --- |
| TAM이 $100B라서 성장 여지가 크다 | 회사가 실제 접근 가능한 SAM은 얼마이고, 그중 현실적으로 몇 %를 차지할 수 있는가? |
| 시장 CAGR이 높다 | 그 성장률이 이 회사 매출 성장으로 연결되는가? |
| 점유율이 낮아서 upside가 크다 | 점유율을 높일 제품력, 유통력, 가격경쟁력, 해자가 있는가? |
| 시장이 크니 좋은 기업이다 | 시장은 크지만 profit pool이 다른 레이어에 있을 수 있다 |

# 4. Market / Share 분석에서 특히 중요한 관점

## 4-1. TAM은 출발점이지 결론이 아님

| 질문 | 의미 |
| --- | --- |
| 회사가 말한 TAM은 무엇을 포함하는가? | 과장 가능성 확인 |
| 회사가 실제 접근 가능한 시장은 어디까지인가? | SAM 파악 |
| 현실적으로 차지 가능한 시장은 얼마인가? | SOM 파악 |
| 현재 매출 대비 얼마나 큰가? | 성장 runway 확인 |
| 점유율을 높일 근거가 있는가? | Competition / Moat 연결 |

---

## 4-2. 시장 성장과 회사 성장은 다를 수 있음

| 경우 | 해석 |
| --- | --- |
| 시장 성장률 > 회사 성장률 | 점유율 하락 가능성 |
| 회사 성장률 > 시장 성장률 | 점유율 확대 가능성 |
| 시장은 성장하지만 가격은 하락 | 매출 성장률이 둔화될 수 있음 |
| 시장은 크지만 경쟁이 심함 | profit pool이 작을 수 있음 |
| 시장은 작지만 회사 점유율이 높고 margin이 좋음 | niche compounder 가능성 |

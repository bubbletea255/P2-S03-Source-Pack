# # 가치투자 리서치 21단계 구조화 버전

# 가치투자 리서치 21단계: 구조화 버전

## 0. 먼저 전체 그림

21단계를 한 줄로 압축하면 이렇게 볼 수 있습니다.

> **“무엇을 볼 것인가 → 이 회사가 좋은가 → 얼마의 가치가 있는가 → 살 것인가 → 산 뒤 어떻게 관리할 것인가”**
> 

즉, 21단계는 단순한 체크리스트가 아니라 아래처럼 이어지는 **투자 의사결정 파이프라인**입니다.

| 큰 흐름 | 핵심 질문 | 해당 단계 |
| --- | --- | --- |
| A. 투자 기준과 후보 발굴 | 나는 어떤 기업을 찾고 있고, 무엇을 분석할 것인가? | 0~2 |
| B. 이해 기반 구축 | 이 산업과 회사는 어떻게 작동하는가? | 3~7 |
| C. 경쟁우위와 품질 판단 | 이 회사는 좋은 기업인가, 오래 이길 수 있는가? | 8~11 |
| D. 미래와 가격 판단 | 좋은 기업이라면 지금 가격이 매력적인가? | 12~16 |
| E. 최종 의사결정 | 그래서 살 것인가, 얼마나 살 것인가? | 17~18 |
| F. 사후 관리와 학습 | 산 뒤 thesis가 유지되는가, 나는 무엇을 배웠는가? | 19~21 |

# Phase 0. 투자 기준 설정

## “나는 어떤 투자 게임을 할 것인가?”

| 단계 | 이름 | 핵심 산출물 |
| --- | --- | --- |
| 0 | 투자 기준 설정 | 기업 유형, 요구수익률, 최대 비중 |

이 단계는 개별 기업 분석 전에 먼저 정해야 하는 **투자자의 운영 원칙**입니다.

예를 들어 같은 기업을 봐도 투자 기준에 따라 판단이 완전히 달라집니다.

| 기준 | 예시 |
| --- | --- |
| 선호 기업 유형 | Compounder, 성장주, turnaround, deep value |
| 최소 요구수익률 | 연 10%, 15%, 20% 등 |
| 최대 비중 | 단일 종목 5%, 10%, 20% |
| 회피 대상 | 과도한 부채, 지속적 희석, 구조적 적자, 불투명한 회계 |
| 보유 기간 | 1~2년, 3~5년, 10년 이상 |
| 감내 가능한 변동성 | 고성장주 변동성 허용 여부 |

## 왜 중요한가?

투자 기준이 없으면 분석을 아무리 잘해도 결론이 흔들립니다.

예를 들어:

- Compounder 투자자는 비싼 밸류에이션도 일부 감수할 수 있음
- Deep value 투자자는 사업의 질이 낮아도 가격이 충분히 싸면 관심을 가질 수 있음
- Turnaround 투자자는 경영진 교체, 비용 절감, 부채 구조를 더 중요하게 봄
- Cyclical recovery 투자자는 기업 품질보다 사이클 위치를 먼저 봄

즉, 이 단계는 **분석의 렌즈를 정하는 단계**입니다.

# Phase 2. 사업 이해 / 산업 구조 파악

## “이 회사는 어떤 산업에서, 어떤 방식으로 돈을 버는가?”

| 단계 | 이름 | 핵심 산출물 |
| --- | --- | --- |
| 3 | Source Pack | 공시, 컨콜, IR, 산업자료 |
| 4 | Industry Primer | 산업 구조와 핵심 용어 |
| 5 | Value Chain | profit pool map |
| 6 | Business Model | 제품, 고객, 가격, 매출 공식 |
| 7 | Market / Share | TAM / SAM / SOM, 점유율 |

이 Phase는 **투자 판단 전에 사업을 이해하는 단계**입니다.

가치투자에서 가장 위험한 실수 중 하나는 **사업을 잘 모르면서 숫자만 보는 것**입니다.
이 단계는 그 위험을 줄이기 위한 과정입니다.

---

## 3. Source Pack

분석의 원자료를 모읍니다.

| 자료 | 목적 |
| --- | --- |
| 10-K | 사업, 리스크, 재무제표의 기본 자료 |
| 10-Q | 최근 분기 변화 확인 |
| S-1 | 신규 상장 기업의 사업 구조 확인 |
| Proxy | 경영진 보상, 지배구조 확인 |
| Earnings call | 경영진 설명과 애널리스트 우려 확인 |
| Investor presentation | 회사가 강조하는 전략 확인 |
| 경쟁사 공시 | 상대적 위치 확인 |
| 산업 리포트 | 시장 규모, 성장률, 산업 구조 확인 |

중요한 점은 **회사 자료만 보면 안 된다**는 것입니다.

회사 자료는 당연히 자사에 유리하게 설명합니다.
그래서 경쟁사 자료, 고객 관점 자료, 산업 자료를 함께 봐야 합니다.

## 4. Industry Primer

산업을 이해하는 단계입니다.

| 질문 | 예시 |
| --- | --- |
| 이 산업은 왜 존재하는가? | 고객이 어떤 문제를 해결하려고 돈을 내는가 |
| 산업의 핵심 용어는 무엇인가? | ARR, NRR, throughput, reimbursement, attach rate 등 |
| 구매자는 누구인가? | 기업, 병원, 연구소, 소비자, 광고주 등 |
| 구매 결정 기준은 무엇인가? | 가격, 성능, 신뢰성, 규제 승인, ROI |
| 산업 성장은 무엇이 결정하는가? | 규제, 기술 발전, 예산, 경기, 인프라 투자 |

이 단계는 특히 당신처럼 기술주, 소프트웨어, 헬스케어, 반도체를 보는 투자자에게 매우 중요합니다.
산업 용어를 이해하지 못하면 경영진 발언과 실적 지표를 잘못 해석할 수 있습니다.

## 5. Value Chain

산업 전체에서 **누가 돈을 벌고, 누가 비용을 부담하는지** 보는 단계입니다.

예를 들어 AI 인프라를 보면:

```
전력 / 데이터센터
→ GPU / ASIC
→ HBM / 메모리
→ 네트워크 / 광통신
→ 서버 / 랙 시스템
→ 클라우드 플랫폼
→ AI 모델
→ 애플리케이션
→ 최종 고객
```

여기서 중요한 질문은:

| 질문 | 의미 |
| --- | --- |
| 어느 레이어가 병목인가? | 가격결정력이 생길 가능성 |
| 어느 레이어의 공급자가 적은가? | 해자 가능성 |
| 어느 레이어가 commoditize될 가능성이 큰가? | 장기 margin 압박 |
| 고객이 가장 큰 돈을 지불하는 곳은 어디인가? | profit pool 위치 |
| 이 회사는 밸류체인에서 얼마나 중요한 위치인가? | “없으면 안 되는 기업”인지 판단 |

## 6. Business Model

이제 개별 회사로 들어갑니다.

핵심은 회사 설명을 단순히 외우는 것이 아니라, **매출 공식과 이익 공식으로 바꾸는 것**입니다.

| 구분 | 봐야 할 것 |
| --- | --- |
| 제품 / 서비스 | 무엇을 파는가 |
| 고객 | 누구에게 파는가 |
| 가격 구조 | 구독, 사용량 기반, 건당 수수료, 장비 판매, consumables |
| 매출 공식 | 고객 수 × 가격 × 사용량 × retention |
| 비용 구조 | COGS, R&D, S&M, G&A, capex |
| 이익 공식 | gross profit → operating profit → FCF |
| 확장성 | 매출이 늘 때 비용이 얼마나 같이 늘어나는가 |

## 좋은 사업모델의 예

| 특징 | 의미 |
| --- | --- |
| 반복 매출 | 예측 가능성 높음 |
| 높은 gross margin | 확장성 가능 |
| 낮은 churn | 고객 락인 |
| 사용량 증가 | 고객 성장과 함께 매출 증가 |
| 낮은 marginal cost | operating leverage 가능 |
| 높은 switching cost | 해자 가능 |

---

## 7. Market / Share

여기서는 “시장이 크다”에서 멈추면 안 됩니다.

시장 규모는 보통 아래처럼 나눠야 합니다.

| 구분 | 의미 |
| --- | --- |
| TAM | 이론적 전체 시장 |
| SAM | 회사가 실제로 접근 가능한 시장 |
| SOM | 현실적으로 차지할 수 있는 시장 |

예를 들어 TAM이 $100B라고 해도, 실제로 회사가 도달 가능한 시장이 $10B이고, 그중 현실적 점유율이 10%라면 장기 매출 기회는 $1B일 수 있습니다.

## 이 단계의 핵심 질문

| 질문 | 의미 |
| --- | --- |
| 시장이 실제로 성장 중인가? | 단순 마케팅 숫자인지 확인 |
| 회사가 접근 가능한 시장은 어디까지인가? | TAM 과장 방지 |
| 현재 점유율은 얼마인가? | 성장 runway 판단 |
| 점유율을 높일 근거가 있는가? | 경쟁우위와 연결 |
| 가격 하락이나 commoditization 위험은 없는가? | 매출 성장의 질 판단 |

## “이 회사는 좋은 기업인가, 오래 이길 수 있는가?”

## 8. Competition

경쟁사 비교는 단순히 “누가 경쟁자인가”를 보는 작업이 아닙니다.

진짜 목적은 이것입니다.

> **내가 보고 있는 회사가 정말 최선의 투자 대상인지 확인하는 것**
> 

| 비교 항목 | 이유 |
| --- | --- |
| 제품 성능 | 고객이 왜 선택하는가 |
| 가격 | 가격결정력 또는 가격경쟁 여부 |
| 고객군 | enterprise, SMB, consumer 등 |
| 성장률 | 누가 점유율을 가져가는가 |
| gross margin | 사업 품질 차이 |
| R&D 효율 | 기술 우위 지속 가능성 |
| S&M 효율 | GTM 경쟁력 |
| retention | 고객 만족도와 switching cost |
| FCF margin | 최종 경제성 |
| valuation | 더 좋은 기업을 더 싸게 살 수 있는가 |

경쟁사 분석은 당신이 이미 경험했듯이 투자 결정을 바꿀 수 있습니다.
Unity를 보다가 AppLovin을 발견한 사례가 정확히 이 단계의 가치입니다.

## 9. Moat

해자는 “좋아 보이는 회사”와 “오래 좋은 회사”를 구분합니다.

| 해자 유형 | 확인할 증거 |
| --- | --- |
| Switching cost | 고객 이탈률, NRR, 장기계약, workflow lock-in |
| Network effect | 사용자 증가가 제품 가치 증가로 연결되는가 |
| Cost advantage | 규모의 경제, 낮은 생산비, 인프라 효율 |
| Intangible assets | 브랜드, 특허, 규제 승인, 데이터 |
| Efficient scale | 시장 규모가 제한되어 신규 진입 유인이 낮은가 |
| Data advantage | 데이터 축적이 제품 개선으로 이어지는가 |
| Ecosystem lock-in | 파트너, API, 통합, marketplace |

중요한 것은 **해자 후보와 해자 증거를 구분하는 것**입니다.

| 약한 분석 | 강한 분석 |
| --- | --- |
| 이 회사는 데이터 해자가 있다 | 데이터가 제품 성능을 높이고, 고객 retention과 pricing power로 연결되는지 확인 |
| 이 회사는 플랫폼 기업이다 | 제품 간 cross-sell, attach rate, multi-product adoption을 확인 |
| 고객이 바꾸기 어렵다 | churn, NRR, migration cost, 계약기간을 확인 |

## 10. Management

경영진은 특히 성장주에서 매우 중요합니다.

| 항목 | 봐야 할 것 |
| --- | --- |
| CEO 배경 | 창업자, 기술자, 영업형, 재무형 |
| 과거 실행력 | 약속한 전략을 실제로 달성했는가 |
| 자본배분 | R&D, M&A, 자사주, 부채, 희석 |
| 보상 구조 | 주주와 이해관계가 일치하는가 |
| 커뮤니케이션 | 투명한가, 과장하는가 |
| 위기 대응 | 실적 부진 때 어떻게 대응했는가 |

## 경영진 분석의 핵심

좋은 경영진은 단순히 말을 잘하는 사람이 아닙니다.

- 좋은 시장을 선택하고
- 자본을 높은 수익률로 배분하고
- 어려운 시기에 비용과 전략을 조정하고
- 장기 주주가치를 훼손하지 않는 사람입니다.

---

## 11. Financial Quality

여기서는 단순히 실적 숫자를 정리하는 것이 아니라, **성장의 질**을 봅니다.

| 항목 | 질문 |
| --- | --- |
| Revenue growth | 성장률이 유지되는가 |
| Gross margin | 제품·서비스의 기본 경제성이 좋은가 |
| Operating leverage | 매출 증가가 이익 증가로 연결되는가 |
| FCF | 회계상 이익이 현금으로 전환되는가 |
| SBC | 주주 희석을 비용처럼 봐도 괜찮은가 |
| Dilution | 장기 주당 가치가 늘고 있는가 |
| Balance sheet | 위기 때 버틸 수 있는가 |
| Working capital | FCF가 일시적으로 부풀려진 것은 아닌가 |
| Capex | 성장을 위해 필요한 현금투자가 큰가 |

이 단계의 핵심은 “성장하고 있다”가 아니라:

> **성장이 주주가치로 전환되고 있는가?**
> 

입니다.

# Phase 4. 미래 숫자 / 밸류에이션 판단

## “좋은 회사라면, 지금 가격이 좋은가?”

| 단계 | 이름 | 핵심 산출물 |
| --- | --- | --- |
| 12 | Forecast | 미래 매출·마진·FCF 모델 |
| 13 | Valuation | DCF, multiple, reverse valuation |
| 14 | Variant Perception | 시장과 다른 내 핵심 관점 |
| 15 | Risk / Bear Case | downside, kill criteria |
| 16 | Catalyst | 재평가 트리거 |

Phase 3까지는 “좋은 기업인가?”를 봤습니다.
Phase 4는 “좋은 투자 대상인가?”를 봅니다.

좋은 기업과 좋은 투자는 다릅니다.
좋은 기업도 너무 비싸면 나쁜 투자가 될 수 있습니다.

---

## 12. Forecast

미래 숫자를 예측하는 단계입니다.

여기서 중요한 것은 정확한 예측이 아닙니다.
핵심은 **무엇이 미래 가치를 결정하는지 이해하는 것**입니다.

| 예측 항목 | 핵심 driver |
| --- | --- |
| Revenue | 고객 수, 가격, 사용량, retention, 시장 성장률 |
| Gross margin | 제품 mix, 규모의 경제, 인프라 비용 |
| Operating margin | R&D, S&M, G&A 레버리지 |
| FCF margin | capex, working capital, SBC-adjusted profitability |
| Share count | SBC, 전환사채, 자사주 매입 |
| Net cash / debt | FCF, M&A, 부채상환 |

## 좋은 forecast의 특징

| 약한 forecast | 강한 forecast |
| --- | --- |
| 매출이 매년 20% 성장한다고 가정 | 고객 수, ARPU, 사용량, retention으로 분해 |
| FCF margin이 25% 된다고 가정 | gross margin, opex ratio, capex, SBC를 연결 |
| multiple 30배 적용 | 왜 해당 multiple이 가능한지 ROIC, 성장률, 안정성으로 설명 |

---

## 13. Valuation

밸류에이션은 “정답”을 찾는 작업이 아니라 **가격과 기대수익률의 관계를 보는 작업**입니다.

| 방법 | 적합한 상황 |
| --- | --- |
| DCF | 장기 FCF 가정이 가능한 기업 |
| EV/Sales | 아직 이익이 없지만 gross margin이 높은 성장주 |
| EV/Gross Profit | 수익성 전환 전 SaaS, 소프트웨어, 데이터 기업 |
| EV/FCF | FCF가 안정적으로 나오는 기업 |
| P/E | 순이익이 의미 있는 성숙 기업 |
| SOTP | 사업부별 가치가 다른 기업 |
| NAV / Liquidation value | deep value, 자산주 |
| Mid-cycle EBITDA | cyclical 기업 |

당신이 자주 쓰는 reverse valuation은 매우 좋은 방법입니다.

핵심 질문은:

- 현재 EV는 5년 뒤 어느 정도 매출을 반영하는가?
- 어느 정도 FCF margin이 필요하다고 보는가?
- terminal multiple은 얼마나 높아야 하는가?
- 그 가정이 현실적인가?
- 현재 가격에서 기대수익률이 요구수익률보다 높은가?

---

## 14. Variant Perception

이 단계는 정말 중요합니다.

전문 투자에서 좋은 thesis는 보통 이렇게 생겼습니다.

> “이 회사는 좋다”가 아니라
“시장이 이 회사를 잘못 보고 있고, 나는 그 이유를 설명할 수 있다.”
> 

## 예시

| 약한 thesis | 강한 thesis |
| --- | --- |
| Datadog은 좋은 회사다 | 시장은 보안 제품 확장에 따른 장기 TAM 확대와 gross profit 성장률을 과소평가하고 있다 |
| AppLovin은 성장률이 높다 | 시장은 AXON 기반 광고 효율 개선이 단기 이벤트가 아니라 구조적 share gain이라고 충분히 반영하지 못하고 있다 |
| Natera는 매출이 잘 성장한다 | 시장은 비용 증가를 우려하지만, 핵심 검사량 증가와 reimbursement 개선이 장기 FCF 전환으로 이어질 가능성을 낮게 보고 있다 |
| Wolfspeed는 싸다 | 시장은 post-reorg equity의 생존 가능성을 과소평가하고 있지만, 실제로는 업황 회복 시 normalized revenue 대비 EV가 낮다 |

Variant perception은 최종 투자 메모의 중심 문장입니다.

---

## 15. Risk / Bear Case

리스크는 단순히 나열하면 안 됩니다.

좋은 리스크 분석은 아래 세 가지를 포함합니다.

| 구분 | 의미 |
| --- | --- |
| Risk | 무엇이 잘못될 수 있는가 |
| Bear case | 잘못되면 숫자가 어떻게 바뀌는가 |
| Kill criteria | 어떤 신호가 나오면 thesis가 깨졌다고 볼 것인가 |

## 예시

| 리스크 | Kill criteria |
| --- | --- |
| 경쟁 심화 | 핵심 제품 성장률이 시장 성장률보다 낮아짐 |
| 해자 약화 | NRR 하락, churn 상승, 신규 고객 둔화 |
| 수익성 미전환 | 매출 성장에도 operating margin 개선 없음 |
| 희석 | 주가 상승 없이 share count가 계속 증가 |
| 부채 위험 | refinancing 비용 급등, covenant 압박 |
| 경영진 신뢰 훼손 | 가이던스 반복 미스, 설명 변경 |

---

## 16. Catalyst

Catalyst는 시장이 내 thesis를 알아차리게 만드는 계기입니다.

| Catalyst 유형 | 예시 |
| --- | --- |
| 실적 | 매출 재가속, margin 개선, FCF 흑자 |
| 제품 | 신제품 adoption, cross-sell 성공 |
| 산업 | 업황 바닥 통과, 가격 반등 |
| 자본배분 | 자사주 매입, 부채상환, 비핵심 자산 매각 |
| 구조조정 | 비용 절감, 사업부 매각, 경영진 교체 |
| 규제 / 보험 | reimbursement 확대, 승인 획득 |
| M&A | 인수 또는 피인수 가능성 |

Catalyst가 없다고 무조건 투자하면 안 되는 것은 아닙니다.
Compounder는 시간이 catalyst가 될 수 있습니다.

하지만 turnaround, cyclical, deep value에서는 catalyst가 훨씬 중요합니다.

---

# Phase 5. 최종 투자 결정

## “그래서 살 것인가, 얼마나 살 것인가?”

| 단계 | 이름 | 핵심 산출물 |
| --- | --- | --- |
| 17 | Final Memo | 매수 / 보류 / 제외 판단 |
| 18 | Position Sizing | initial / full / max 비중 |

이 단계는 분석을 실제 투자 행동으로 바꾸는 단계입니다.

---

## 17. Final Memo

Final Memo는 단순 요약이 아닙니다.
투자 판단을 남기는 문서입니다.

좋은 Final Memo에는 아래가 들어갑니다.

| 항목 | 질문 |
| --- | --- |
| 핵심 thesis | 왜 이 종목인가 |
| 기업 유형 | compounder, turnaround, cyclical, deep value 중 무엇인가 |
| 사업 품질 | 좋은 사업인가 |
| 해자 | 지속 가능한 경쟁우위가 있는가 |
| 재무 품질 | 성장과 FCF가 연결되는가 |
| 밸류에이션 | 현재 가격에서 기대수익률이 충분한가 |
| variant perception | 시장과 다른 내 관점은 무엇인가 |
| 핵심 리스크 | 내가 틀릴 수 있는 이유는 무엇인가 |
| kill criteria | 무엇이 나오면 thesis가 깨지는가 |
| catalyst | 무엇이 재평가를 유발할 수 있는가 |
| 결론 | Buy / Watch / Pass / Sell |

---

## 18. Position Sizing

좋은 기업이라고 무조건 크게 사면 안 됩니다.
비중은 확신도, upside, downside, 변동성, 유동성, 포트폴리오 중복도를 반영해야 합니다.

| 구분 | 의미 |
| --- | --- |
| Initial position | 아직 확신이 완전하지 않을 때 시작 비중 |
| Full position | thesis가 검증되고 가격도 매력적일 때 목표 비중 |
| Max position | 아무리 좋아도 넘지 않을 최대 비중 |
| Add condition | 어떤 조건에서 추가매수할지 |
| Trim condition | 어떤 조건에서 줄일지 |
| Exit condition | 어떤 조건에서 완전히 팔지 |

## 유형별 사이징 차이

| 유형 | 일반적 사이징 원칙 |
| --- | --- |
| Compounder | 확신이 높으면 비교적 큰 비중 가능 |
| Turnaround | 성공 확률이 낮으므로 보수적 비중 |
| Cyclical Recovery | 사이클 오판 리스크 때문에 단계적 매수 |
| Deep Value | value trap 가능성 때문에 basket 접근도 고려 |

---

# Phase 6. 사후 관리 / 피드백

## “산 뒤 thesis가 유지되는가, 나는 무엇을 배웠는가?”

| 단계 | 이름 | 핵심 산출물 |
| --- | --- | --- |
| 19 | Monitoring | 실적, KPI, valuation refresh |
| 20 | Decision Journal | 의사결정 기록 |
| 21 | Post-mortem | 맞은 이유 / 틀린 이유 복기 |

이 단계가 없으면 투자 실력이 쌓이지 않습니다.

---

## 19. Monitoring

Monitoring은 뉴스만 보는 게 아닙니다.
처음 세운 thesis가 실제로 맞아가는지 확인하는 작업입니다.

| 모니터링 항목 | 질문 |
| --- | --- |
| 실적 | 매출, margin, FCF가 thesis와 일치하는가 |
| KPI | 내가 보기로 한 핵심 지표가 좋아지는가 |
| 경쟁 | 경쟁사 대비 성과가 좋아지는가 |
| 밸류에이션 | 주가 상승 후 기대수익률이 낮아졌는가 |
| 리스크 | kill criteria에 가까워지는 신호가 있는가 |
| 경영진 | 말과 실행이 일치하는가 |

## Monitoring 결과

| 결과 | 행동 |
| --- | --- |
| Thesis 강화 + 가격 매력 | 추가매수 검토 |
| Thesis 유지 + 가격 적정 | 보유 |
| Thesis 유지 + 가격 과도 | 일부 축소 검토 |
| Thesis 약화 | 비중 축소 |
| Thesis 훼손 | 매도 검토 |

---

## 20. Decision Journal

Decision Journal은 “왜 샀는지”를 기록하는 것입니다.

기록해야 할 항목:

| 항목 | 내용 |
| --- | --- |
| 매수일 | 언제 샀는가 |
| 매수가 | 얼마에 샀는가 |
| 당시 thesis | 왜 샀는가 |
| 당시 기대수익률 | 어떤 upside를 봤는가 |
| 핵심 가정 | 무엇이 맞아야 하는가 |
| 리스크 | 무엇이 틀릴 수 있는가 |
| 추가매수 조건 | 무엇이 확인되면 더 살 것인가 |
| 매도 조건 | 무엇이 깨지면 팔 것인가 |
| 감정 상태 | 급락 공포, FOMO, 확신 과잉 여부 |

이 단계는 특히 중요합니다.
사람은 나중에 자신의 과거 생각을 바꿔 기억하는 경향이 있습니다.

Decision Journal이 없으면 “내가 왜 틀렸는지”를 정확히 배우기 어렵습니다.

---

## 21. Post-mortem

Post-mortem은 결과가 나온 뒤 복기하는 단계입니다.

| 질문 | 목적 |
| --- | --- |
| 내가 맞았다면 왜 맞았는가? | 운과 실력을 구분 |
| 내가 틀렸다면 무엇을 놓쳤는가? | 반복 실수 방지 |
| 숫자가 틀렸는가, thesis가 틀렸는가? | 오류 유형 분류 |
| 경영진을 과신했는가? | 정성 판단 점검 |
| 밸류에이션을 과소평가했는가? | 가격 discipline 점검 |
| 경쟁사를 충분히 봤는가? | 대체 투자 기회 점검 |
| 사이클을 잘못 봤는가? | cyclical 분석 개선 |
| 포지션이 너무 컸는가? | 리스크 관리 개선 |

Post-mortem은 투자 실력의 누적 장치입니다.

# 단계별 관계를 더 깊게 보면

## 1. Phase 2와 Phase 3의 차이

| Phase | 질문 | 예시 |
| --- | --- | --- |
| Phase 2 사업 이해 | 이 회사는 어떻게 돈을 버는가? | Datadog은 observability와 security 제품을 subscription으로 판매 |
| Phase 3 품질 판단 | 이 회사가 오래 돈을 잘 벌 수 있는가? | 고객 switching cost, multi-product adoption, gross margin, FCF 전환력 확인 |

Phase 2에서 멈추면 “공부”입니다.
Phase 3까지 가야 “투자 분석”이 됩니다.

---

## 2. Phase 3와 Phase 4의 차이

| Phase | 질문 | 예시 |
| --- | --- | --- |
| Phase 3 품질 판단 | 좋은 기업인가? | 성장률, 해자, 경영진, 재무 품질 |
| Phase 4 가격 판단 | 좋은 투자인가? | 현재 EV가 미래 FCF를 과도하게 반영했는가 |

좋은 기업과 좋은 투자는 다릅니다.

- 좋은 기업 + 너무 비싼 가격 = 낮은 기대수익률
- 보통 기업 + 너무 싼 가격 + catalyst = 좋은 투자 가능
- 나쁜 기업 + 싼 가격 = value trap 가능

---

## 3. Phase 4와 Phase 5의 차이

| Phase | 질문 | 예시 |
| --- | --- | --- |
| Phase 4 분석 | 가격이 매력적인가? | upside/downside 계산 |
| Phase 5 행동 | 실제로 얼마를 살 것인가? | 3% 시작, 7%까지 확대 가능 |

투자에서 분석과 실행은 다릅니다.

예를 들어:

- upside가 크지만 불확실성이 크면 소액만 살 수 있음
- compounder라서 확신이 높으면 더 큰 비중 가능
- turnaround는 upside가 커도 실패 확률 때문에 비중 제한 필요

## 한 줄 결론

이 21단계 프로세스의 핵심은 **“기업 공부 → 기업 품질 판단 → 가격 판단 → 투자 행동 → 사후 검증”**입니다.

당신이 앞으로 템플릿을 만들 때도 이 순서대로 가면 됩니다.

1. 먼저 **Quick Screen 템플릿**
2. 그다음 **Business Model / Industry Primer 템플릿**
3. 그다음 **Competition / Moat 템플릿**
4. 그다음 **Risk / Final Memo / Monitoring 템플릿**

이 순서로 만들면 전체 투자 리서치 운영체계가 자연스럽게 완성됩니다.

# 가치투자 리서치 업무 전체 구조

## AI를 붙이기 전에 먼저 만들어야 할 “투자 리서치 운영체계”

먼저 한계를 분명히 하겠습니다. 실제 월스트리트 상위 펀드의 내부 리서치 매뉴얼, 투자위원회 메모, 포지션 사이징 규칙은 대부분 비공개입니다. 그래서 “상위 0.1%가 정확히 이렇게 한다”고 단정할 수는 없습니다. 다만 CFA Institute의 기업분석·포트폴리오 관리·밸류에이션 자료, SEC의 공시 활용 가이드, Morningstar의 경제적 해자 프레임워크, FINRA의 AI 활용·위험관리 자료를 종합하면, 전문 투자자가 어떤 순서와 논리로 기업을 분석하는지는 상당히 구조화해서 재구성할 수 있습니다. CFA Institute도 기업 리서치 보고서가 과거·현재 재무, 산업과 경쟁사, 미래 재무제표 전망, 밸류에이션, 투자 의견, 리스크로 구성된다고 설명합니다. ([CFA Institute](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/company-analysis-past-and-present))

# 1. 핵심 결론

## 당신은 이미 “기업 단위 딥다이브”는 상당히 잘하고 있음

당신이 이미 하고 있는 작업은 일반 개인투자자 수준을 꽤 넘어섭니다.

- 컨퍼런스콜 번역 및 분석
- 실적 Fact Layer 정리
- 밸류에이션 / reverse valuation
- 사업부, 제품, 고객, 시장 규모, 점유율, 경쟁사, 리스크, 밸류체인 분석
- Bull / Base / Bear 시나리오 사고
- AI를 템플릿화해서 반복 업무에 활용

이건 이미 **전문 애널리스트의 “리서치 생산 방식”에 가까운 방향**입니다.

## 다만 아직 부족한 부분은 “분석 자체”보다 “투자 의사결정 시스템” 쪽에 있음

당신의 현재 구조는 강하지만, 상위권 투자자가 반드시 갖추는 몇 가지 업무가 상대적으로 덜 명시화되어 있습니다.

| 구분 | 현재 상태 | 보완해야 할 핵심 |
| --- | --- | --- |
| 기업 이해 | 강함 | 사업모델을 “매출 공식”과 “이익 공식”으로 더 정형화 |
| 시장 / 점유율 | 강함 | TAM보다 실제 도달 가능한 SAM / SOM, 침투율, 가격 하락 가능성까지 연결 |
| 경쟁사 / 해자 | 중요성을 잘 인식 | 반복 가능한 경쟁사 비교 템플릿과 해자 점수표 필요 |
| 재무 / 밸류에이션 | 매우 강함 | 재무 모델의 가정-결과 연결표, thesis 변경 기준 보강 |
| 리스크 | 중요성을 잘 인식 | 리스크 목록이 아니라 “kill criteria”와 downside valuation으로 전환 필요 |
| 사후 모니터링 | 부분적으로 수행 | 실적 발표 후 thesis tracker / decision journal 필요 |
| 포트폴리오 관점 | 상대적으로 약함 | 포지션 사이징, 기회비용, 매수·추가매수·축소 기준 필요 |
| 투자 아이디어 발굴 | 명시적 프로세스 부족 | universe → screening → watchlist → deep dive 파이프라인 필요 |

# 2. 전문 가치투자자의 전체 업무 지도

전문 투자자는 보통 “좋은 회사 찾기”에서 끝내지 않습니다. 전체 프로세스는 아래처럼 돌아갑니다.

| 단계 | 업무 | 핵심 질문 | 산출물 |
| --- | --- | --- | --- |
| 0 | 투자 철학 / 포트폴리오 기준 설정 | 나는 어떤 기업을, 어떤 기간으로, 어떤 리스크까지 감수하고 살 것인가? | 투자 원칙, 금지 대상, 요구수익률, 포지션 한도 |
| 1 | 투자 아이디어 발굴 | 어떤 산업·기업을 볼 것인가? | 후보군 리스트 |
| 2 | 1차 스크리닝 | 이 기업은 시간을 쓸 가치가 있는가? | Pass / Watch / Reject |
| 3 | Source Pack 구축 | 어떤 원자료를 기준으로 분석할 것인가? | 10-K, 10-Q, S-1, Proxy, IR, 컨콜, 산업자료 |
| 4 | 산업 / 배경지식 습득 | 이 산업은 어떻게 돈을 버는가? | 산업 프라이머 |
| 5 | 밸류체인 / profit pool 분석 | 산업 내에서 누가 돈을 버는가? | 밸류체인 지도 |
| 6 | 사업모델 분석 | 회사는 어떤 문제를 해결하고, 누구에게, 어떻게 돈을 받는가? | 사업모델 맵 |
| 7 | 시장 규모 / 점유율 분석 | 성장 여지는 얼마나 크고, 이 회사가 실제로 가져갈 몫은 얼마인가? | TAM / SAM / SOM, share model |
| 8 | 경쟁사 / 경제적 해자 분석 | 이 회사가 왜 이길 수 있고, 얼마나 오래 이길 수 있는가? | 경쟁사 비교표, moat scorecard |
| 9 | 경영진 / 전략 / 자본배분 분석 | 경영진은 자본을 현명하게 쓰는가? | 경영진 평가, M&A / R&D / GTM 평가 |
| 10 | 재무제표 / 실적 품질 분석 | 성장과 이익이 실제 경제적 가치로 전환되는가? | Fact Layer, quality of earnings, FCF 분석 |
| 11 | 예측 모델 / 핵심 KPI 설정 | 향후 매출·마진·FCF를 움직이는 변수는 무엇인가? | revenue driver model, KPI dashboard |
| 12 | 밸류에이션 | 좋은 회사인데 지금 가격도 좋은가? | DCF, multiple, reverse valuation |
| 13 | 리스크 / downside / kill criteria | 내가 틀렸다면 무엇이 먼저 나타날까? | 리스크 레지스터, bear case, thesis kill points |
| 14 | 투자 메모 작성 | 왜 지금 사야 하며, 무엇이 시장과 다른 내 관점인가? | 최종 투자 메모 |
| 15 | 포트폴리오 편입 / 사이징 | 얼마를 살 것인가? 언제 더 사고, 언제 줄일 것인가? | 포지션 사이징, 매수·매도 계획 |
| 16 | 사후 모니터링 / 피드백 | thesis가 유지되는가, 깨졌는가? | 실적 업데이트, decision journal, post-mortem |

CFA Institute는 포트폴리오 관리 프로세스를 투자자 목적과 제약 파악, 투자정책 수립, 자산배분, 증권분석, 포트폴리오 구성, 모니터링·리밸런싱, 성과 측정·보고의 흐름으로 설명합니다. 즉, 개별 기업 분석은 전체 투자 프로세스의 일부이고, 최종적으로는 포트폴리오 안에서 어떤 역할을 하는지까지 연결되어야 합니다. ([CFA Institute](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/portfolio-management-overview))

# 3. 당신이 이미 잘하고 있는 부분

## 3-1. 실적과 밸류에이션을 분리해서 보는 점

당신은 이미 실적을 먼저 Fact Layer로 정리하고, 그다음 밸류에이션을 판단합니다. 이건 매우 좋은 습관입니다.

- 좋은 순서:
    1. 실적 숫자 정리
    2. 성장률, 마진, FCF, SBC, 희석률 확인
    3. 현재 EV와 multiple 계산
    4. reverse valuation으로 시장 기대치 역산
    5. Bull / Base / Bear 시나리오 비교

이 방식은 “좋은 회사니까 산다”가 아니라, **좋은 회사가 현재 가격에서 기대수익률을 제공하는지**를 검증하는 방식입니다. CFA Institute도 밸류에이션은 미래 투자수익과 관련된 변수, 유사 자산과의 비교, 청산가치 등을 기반으로 자산 가치를 추정하는 과정이며, 밸류에이션 능력은 투자 성공의 중요한 요소라고 설명합니다. ([CFA Institute](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/equity-valuation-applications-and-processes))

---

## 3-2. 컨퍼런스콜을 단순 번역이 아니라 “신호”로 읽는 점

컨퍼런스콜은 숫자보다 경영진의 설명 방식, 질문 회피 여부, 톤 변화, 반복되는 전략 키워드를 읽는 것이 중요합니다.

당신은 이미 다음을 하고 있습니다.

- CEO / CFO / Q&A를 분리해서 읽음
- 숫자를 정확히 보존
- 경영진 발언을 구조화
- Q&A에서 애널리스트가 무엇을 걱정하는지 파악
- 실적 발표 전후 thesis 변화를 체크

이건 매우 좋은 접근입니다. 다만 앞으로는 컨퍼런스콜 분석을 아래 세 가지로 더 분리하면 좋습니다.

| 구분 | 봐야 할 것 | 목적 |
| --- | --- | --- |
| Fact | 매출, 마진, 가이던스, 고객 수, ARR, backlog 등 | 숫자 확인 |
| Signal | 경영진의 강조점, 톤 변화, 질문 회피, 반복 표현 | 방향성 파악 |
| Thesis Impact | 기존 투자 thesis가 강화됐는지, 약화됐는지 | 보유·추가매수·축소 판단 |

---

## 3-3. 경쟁사 분석의 중요성을 체감한 점

당신이 유니티를 분석하다가 AppLovin을 발견하고, 유니티 비중을 줄이고 AppLovin을 매수한 사례는 매우 중요합니다.

이건 전문 투자자 관점에서도 좋은 사고입니다.

- 경쟁사 분석은 “부가 작업”이 아니라 “원래 투자 thesis를 검증하는 작업”입니다.
- 특정 회사가 좋아 보여도, 경쟁사를 보면 다음이 바뀔 수 있습니다.
    - 실제 승자는 누구인지
    - 어느 회사가 더 좋은 unit economics를 갖는지
    - 누가 고객 데이터를 더 많이 갖는지
    - 누가 더 강한 유통망을 갖는지
    - 누가 더 높은 incremental margin을 낼 수 있는지
    - 원래 투자하려던 회사의 해자가 과대평가됐는지

따라서 당신에게는 **경쟁사 비교 템플릿**이 매우 우선순위가 높습니다.

# 4. 현재 구조에서 가장 크게 보완해야 할 업무

## 4-1. 투자 철학 / 포트폴리오 문맥

당신은 기업을 깊게 보는 능력은 강하지만, 각 기업이 포트폴리오 안에서 어떤 역할을 하는지는 별도 업무로 분리할 필요가 있습니다.

| 질문 | 왜 중요한가 |
| --- | --- |
| 이 종목은 core position인가, satellite position인가? | 비중 결정 기준이 달라짐 |
| 이 기업은 compounder인가, turnaround인가, cyclical recovery인가, deep value인가? | 밸류에이션 방식과 보유 기간이 달라짐 |
| 내 요구수익률은 얼마인가? | 좋은 회사라도 기대수익률이 낮으면 보류해야 함 |
| 같은 돈으로 살 수 있는 더 좋은 대안은 없는가? | 기회비용 판단 |
| thesis가 맞아도 변동성을 견딜 수 있는가? | 포지션 사이징 판단 |

전문 투자자는 기업 하나만 보지 않고, 항상 “이 종목이 내 전체 포트폴리오에서 어떤 역할을 하는가”를 봅니다.

---

## 4-2. 투자 아이디어 발굴과 1차 스크리닝

현재 당신은 관심이 생긴 기업을 매우 깊게 파고드는 방식이 강합니다. 이 방식은 장점이 있지만, 단점도 있습니다.

- 장점:
    - 깊이 있는 이해 가능
    - 특정 산업의 구조를 잘 파악
    - 경쟁사 발견 가능
- 단점:
    - 처음부터 너무 깊게 들어가면 시간 소모가 큼
    - 더 좋은 기회를 놓칠 수 있음
    - 특정 관심 산업에 시야가 갇힐 수 있음

그래서 전문 프로세스에서는 보통 아래처럼 분리합니다.

| 단계 | 목적 | 산출물 |
| --- | --- | --- |
| Universe 구축 | 볼 수 있는 전체 후보군 확보 | 산업별 후보 리스트 |
| Quick Screen | 시간 쓸 가치가 있는지 판단 | 1차 점수표 |
| Watchlist | 아직 싸지 않지만 좋은 기업 관리 | 관심종목 리스트 |
| Deep Dive | 실제 매수 후보만 깊게 분석 | 투자 메모 |
| Portfolio Decision | 실제 비중 결정 | 매수 / 보류 / 제외 |

---

## 4-3. Forecast model, 즉 “미래 숫자 생성 로직”

당신은 과거 실적 정리와 현재 밸류에이션은 강합니다. 다음 단계는 미래 숫자를 만드는 로직을 더 명확히 하는 것입니다.

| 구분 | 현재 많이 하는 작업 | 더 전문적으로 발전시킬 작업 |
| --- | --- | --- |
| 매출 | 과거 성장률 확인 | 매출 driver 분해 |
| 시장 | TAM 확인 | TAM × 침투율 × 점유율 × 가격 |
| 마진 | gross margin / operating margin 확인 | incremental margin / scale economics |
| FCF | FCF margin 확인 | working capital, capex, SBC-adjusted FCF |
| 희석 | share count / SBC 확인 | 5년 후 diluted share count 가정 |
| 밸류에이션 | 현재 multiple 확인 | 미래 FCF와 terminal multiple 역산 |

CFA Institute도 회사 분석에서 매출 분석은 top-down 방식과 bottom-up 방식으로 접근할 수 있고, top-down은 시장 규모·시장 점유율·GDP 성장 같은 driver를 활용하며, bottom-up은 제품군·세그먼트별 판매량과 가격 같은 driver로 분해한다고 설명합니다. ([CFA Institute](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/company-analysis-past-and-present))

## 4-4. Variant perception

상위 투자자가 가장 중요하게 보는 것 중 하나는 “내가 시장과 다르게 보는 지점”입니다.

좋은 회사라는 사실만으로는 부족합니다.

| 약한 thesis | 강한 thesis |
| --- | --- |
| 이 회사는 좋은 회사다 | 시장은 이 회사의 장기 FCF 전환력을 과소평가하고 있다 |
| 매출이 빠르게 성장한다 | 시장은 성장률 둔화를 과도하게 우려하지만, 핵심 segment는 여전히 고성장 중이다 |
| 밸류에이션이 싸다 | 현재 EV는 5년 뒤 Base case FCF의 너무 낮은 multiple을 반영하고 있다 |
| 해자가 있다 | 경쟁사가 모방하기 어려운 데이터 / 유통 / switching cost가 실제 숫자로 확인된다 |
| 경영진이 좋다 | 과거 자본배분 사례와 현재 전략이 일관되며, ROIC 개선으로 연결되고 있다 |

즉, 최종 투자 메모에는 반드시 이 질문이 들어가야 합니다.

- **“시장은 무엇을 잘못 보고 있는가?”**
- **“내가 맞다면 어떤 숫자가 앞으로 나타나야 하는가?”**
- **“내가 틀렸다면 어떤 숫자가 먼저 망가질 것인가?”**

## 4-5. Kill criteria와 사후 모니터링

리스크를 아는 것과 실제로 매도할 기준을 정하는 것은 다릅니다.

전문 투자자는 리스크를 아래처럼 바꿉니다.

| 일반적인 리스크 정리 | 전문적인 리스크 관리 |
| --- | --- |
| 경쟁 심화 가능성 | 핵심 고객 retention이 하락하면 thesis 훼손 |
| 마진 악화 가능성 | gross margin이 2개 분기 연속 하락하고 원인이 구조적이면 재검토 |
| 성장 둔화 가능성 | core segment 성장률이 시장 성장률 아래로 떨어지면 thesis 약화 |
| 밸류에이션 부담 | Base case 기대수익률이 요구수익률 아래로 내려가면 추가매수 금지 |
| 부채 리스크 | refinance 가능성, covenant, maturity wall을 별도 추적 |

이 작업은 반드시 템플릿화해야 합니다. 특히 Wolfspeed 같은 사례에서는 사업 전망보다 **자본구조, 신주 발행, 기존 주주 처리, 실질 EV, 희석**이 훨씬 중요할 수 있습니다.

# 7. 경제적 해자 분석은 별도 템플릿이 필요함

Morningstar는 경제적 해자의 원천을 크게 다섯 가지로 봅니다.

| 해자 원천 | 의미 | 투자자가 봐야 할 증거 |
| --- | --- | --- |
| Intangible assets | 브랜드, 특허, 라이선스, 규제 승인 등 | 가격결정력, 특허 보호, 규제 장벽 |
| Switching costs | 고객이 바꾸기 어려운 구조 | retention, net revenue retention, migration cost |
| Network effect | 사용자가 늘수록 가치가 커지는 구조 | 사용자 수 증가 → 제품 가치 증가 |
| Cost advantage | 경쟁사보다 낮은 비용 구조 | gross margin, scale, procurement, infrastructure |
| Efficient scale | 시장이 소수 기업만 감당 가능한 구조 | 신규 진입 유인 부족, 지역 독점, 제한된 수요 |

Morningstar는 경제적 해자가 기업이 장기간 높은 자본수익률을 유지하게 해주는 지속 가능한 경쟁우위라고 설명하며, 위 다섯 가지를 주요 해자 원천으로 제시합니다. ([Morningstar](https://www.morningstar.com/stocks/how-measure-companys-competitive-advantage?utm_source=chatgpt.com))

당신이 기술주와 성장주를 많이 보므로, 특히 아래 세 가지를 강하게 봐야 합니다.

| 산업 유형 | 가장 중요한 해자 후보 |
| --- | --- |
| SaaS / Cloud / Cybersecurity | switching cost, 데이터 통합, platform breadth |
| Adtech / Marketplace | network effect, data feedback loop, scale advantage |
| AI 진단 / Life science tools | 독점 데이터, 규제·임상 evidence, workflow lock-in |
| Semiconductor / Hardware | cost advantage, supply chain, IP, manufacturing know-how |
| Digital health | 보험 reimbursement, provider network, clinical workflow integration |

# 8. AI를 붙이면 좋은 업무와 사람이 해야 하는 업무

FINRA는 생성형 AI가 방대한 금융·시장 데이터를 분석·종합하고, 큰 문서를 요약하며, SEC filings와 earnings call transcript에서 issuer-specific information을 얻는 데 활용될 수 있다고 설명합니다. 동시에 정확성, 개인정보, 편향, 지식재산권, 악용 가능성 같은 위험도 지적합니다. 따라서 투자 리서치에서 AI는 “최종 판단자”가 아니라 “리서치 보조자 + 검증 대상”으로 써야 합니다.

| 업무 | AI에게 맡기기 좋음 | 사람이 해야 함 |
| --- | --- | --- |
| Source Pack 구축 | 공시, 컨콜, IR자료 목차화 | 어떤 자료를 신뢰할지 판단 |
| 사업 내용 정리 | 제품, 고객, 매출원 정리 | 이 사업이 좋은 사업인지 판단 |
| 산업 프라이머 | 용어, 밸류체인, 주요 플레이어 설명 | 구조적 성장성 판단 |
| 경쟁사 비교 | peer table, 제품 비교, margin 비교 | 진짜 승자 판단 |
| 해자 분석 | 해자 후보 분류 | 해자가 실제 숫자로 증명되는지 판단 |
| 재무 분석 | 표 정리, 성장률, margin, FCF 계산 | 회계 품질과 지속가능성 판단 |
| 밸류에이션 | 계산, 시나리오, sensitivity | 가정의 합리성 판단 |
| 리스크 분석 | bear case, 리스크 목록 | 어떤 리스크가 치명적인지 판단 |
| 투자 메모 | 초안, 구조화, 반론 생성 | 최종 매수·매도 결정 |
| 모니터링 | 실적 변화, KPI 업데이트 | thesis 훼손 여부 판단 |

CFA Institute의 AI in Asset Management 자료도 LLM이 금융 문서의 자연어 처리, 자동 보고서 생성, 금융 분석용 대화형 인터페이스에 기회를 제공한다고 설명합니다. ([CFA Institute Research and Policy Center](https://rpc.cfainstitute.org/sites/default/files/docs/research-reports/rf_aiinassetmanagement_full-monograph_online.pdf))

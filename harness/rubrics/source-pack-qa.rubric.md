# Source Pack QA Rubric

## 평가 항목

| 항목 | 가중치 | 기준 |
|---|---:|---|
| 출처 신뢰성 | 25 | SEC/IR 원자료 우선, fallback 명시 |
| 완전성 | 20 | 필수 자료 범위와 누락 사유 기록 |
| 형식 안정성 | 20 | Markdown 표와 schema 파싱 가능 |
| 다음 하네스 전달성 | 15 | 후속 Phase가 바로 읽을 요약 제공 |
| 오류 처리 | 10 | 실패/미수집/확인 필요 분리 |
| 모델 중립성 | 10 | Claude/Codex adapter가 같은 원장 사용 |

## 채점 방식

각 항목은 1-5점으로 평가한다.
최종 점수는 `항목 점수 / 5 * 가중치`를 모두 합산해 100점 만점으로 계산한다.

## 항목별 1-5점 기준

| 항목 | 1점 | 3점 | 5점 |
|---|---|---|---|
| 출처 신뢰성 | 출처가 불명확하거나 비공식 링크 중심 | SEC/IR 링크가 있으나 fallback과 출처 우선순위가 일부 불명확 | SEC/IR 원자료 우선, fallback, 확인 필요가 명확 |
| 완전성 | 필수 자료 다수가 누락되고 사유 없음 | 핵심 자료는 있으나 일부 누락 사유 또는 범위가 불명확 | 요청 범위, 수집 건수, 누락 사유가 모두 기록 |
| 형식 안정성 | 필수 섹션 누락 또는 표 파싱 불가 | 대부분 파싱 가능하나 일부 섹션 형식 보완 필요 | schema 필수 섹션과 Markdown 표가 모두 안정적 |
| 다음 하네스 전달성 | 후속 하네스가 무엇을 읽어야 할지 알 수 없음 | 다음 하네스 전달 요약은 있으나 자료 우선순위가 약함 | 후속 하네스별 우선 자료와 확인 필요가 명확 |
| 오류 처리 | 실패와 미수집을 생략하거나 확정처럼 표현 | 실패 사유는 있으나 영향 범위 또는 다음 조치가 부족 | 실패, 미수집, 확인 필요, 권장 조치가 분리됨 |
| 모델 중립성 | adapter에 공통 규칙이 복사되어 drift 위험 큼 | 공통 원장을 참조하지만 일부 규칙이 adapter에도 반복 | Claude/Codex adapter가 같은 harness 원장만 참조 |

## 판정

| 점수 | 판정 |
|---:|---|
| 90-100 | 통과 |
| 75-89 | 부분 통과, 경미한 수정 필요 |
| 60-74 | 부분 성공, 후속 하네스 사용 전 수정 필요 |
| 0-59 | 실패, 재수집 또는 schema 수정 필요 |

## 자동 실패 조건

- CIK가 없고 실패 사유도 없음
- 필수 섹션 누락
- Markdown 표 구분선과 데이터 행이 붙어 있음
- 누락 건수가 음수
- SEC/IR 수집 실패를 아무 기록 없이 생략
- 원자료 내용을 분석 리포트처럼 해석하거나 thesis를 작성
- 투자 판단을 확정적으로 작성
- 다음 하네스 전달 요약 누락
